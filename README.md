# E-Commerce Store API Rendering

A responsive e-commerce web application that fetches and displays products from an API. Built with HTML, CSS, and JavaScript to practice API integration, asynchronous programming, dynamic rendering, search functionality, and category filtering.

## Features

* Fetch and display products from an API
* Search products by name
* Filter products by category
* Categories: Men's Clothing, Women's Clothing, Jewelry, and Electronics
* Dynamic product rendering
* Responsive user interface
* Loading state handling
* Error handling for failed API requests

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* Fake Store API

## What I Learned

* API integration using `fetch()`
* Working with asynchronous JavaScript (`async/await`)
* DOM manipulation
* Search and filtering logic
* Dynamic UI updates
* Error handling and debugging
